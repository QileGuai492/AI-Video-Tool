# 19 - 角色一致性方案

> 状态：开发中（已实现角色多角度参考图接口、任务关联角色、多片段尾帧衔接）  
> 最近更新：2026-08-24  
> 所属文档库：[README](../README.md)

## 1. 目标

保证同一角色在以下场景中外貌一致：

- 单次任务内多个片段。
- 跨多个生成任务。
- 跨多个对话会话。

## 2. 整体策略

```text
用户上传参考图
  → 预处理（裁剪、统一光照、多角度生成）
  → 生成角色特征包（多张参考图 + 描述 + 可选 embedding）
  → 生成任务时携带角色特征包
  → 各家 API 尽量使用“图生视频 / 首帧控制 / 角色参考”
  → 质量评估验证一致性，不达标则重试或换方案
```

## 2.1 当前已实现

- 角色库：主参考图 + 多角度参考图，支持上传、查询、删除。
- 任务关联：`character_id` / `character_mappings` 可将角色参考图带入文生图与视频生成。
- 首帧控制：先根据参考图生成真实首帧，再以该首帧作为视频生成起点。
- 多片段尾帧衔接：当任务包含多个片段且携带角色/参考图时，Simple 与 LangGraph 编排器会顺序生成片段，并使用上一段尾帧作为下一段首帧，降低跨片段角色跳变。
- 提示词约束：角色映射会写入提示词（如 `@图片N的角色名`），并加入空间布局与防镜像指令。

当前仍未实现：人脸/角色一致性后处理、基于视觉模型的一致性自动重试、跨对话角色特征包。

## 3. 参考图预处理

- 统一尺寸：建议 1:1 或 3:4，分辨率 ≥ 512px。
- 统一光照：避免过暗 / 过曝。
- 去除背景干扰：可提供纯色背景或透明背景图。
- 多角度生成：使用文生图 API 生成正面、侧面、3/4 侧面等多张参考图。

## 4. 角色特征存储

建议在 `characters` 表基础上扩展：

| 字段 | 说明 |
| --- | --- |
| `reference_image_url` | 主参考图 |
| `multi_view_urls` | 多角度参考图 JSON 数组 |
| `description` | 角色外貌描述，供 LLM 扩写提示词 |
| `embedding` | 可选，角色特征向量 |
| `provider_specific_config` | 各厂商特定参数 |

## 5. 不同 API 的接入方式

| API | 推荐方式 | 说明 |
| --- | --- | --- |
| MiniMax 海螺 | 图生视频 + 首帧 | 将参考图作为首帧或角色图传入 |
| 火山引擎 | 图生视频 + 角色参考 | 按官方参数传入 reference image |
| 可灵 | 图生视频 + 首帧控制 | 使用参考图生成首帧后再生成视频 |
| 开源模型（备选） | LoRA / IP-Adapter | 后续可微调或部署 |

## 6. 跨对话一致性

- 每次生成任务保存“角色特征包快照”。
- 任务参数快照包含：参考图列表、角色描述、使用的模型、提示词。
- 用户选择“跨对话保持角色一致”时，调度 Agent 从角色库读取最新特征包。

## 7. 验证方式

- 生成后对每个片段抽帧。
- 使用视觉语言模型对比参考图与片段中的人脸 / 角色特征。
- 相似度低于阈值时自动重试或更换生成策略。

## 8. 风险与限制

- 各家 API 对角色一致性的支持程度不同，可能需要组合策略。
- 复杂动作 / 大角度转身可能导致一致性下降。
- 多角色一致性属于 Could Have，先保证单角色。
