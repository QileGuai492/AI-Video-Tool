# 05 - 数据模型

> 状态：已评审  
> 最近更新：2026-01-01  
> 所属文档库：[README](../README.md)

## 1. 约定

- 开发环境默认 SQLite，生产环境使用 PostgreSQL。
- 主键统一使用 UUID 或自增 ID，建议后端统一。
- 金额字段使用 `decimal`，避免浮点误差。
- 时间字段统一 UTC 存储。
- 所有外键建议加索引。

## 2. 实体关系概览

```text
users 1───n characters
users 1───n video_tasks
users 1───n templates
users 1───1 settings

video_tasks 1───n video_segments
video_tasks 1───n audio_tracks
```

## 3. 表结构

### 3.1 users（用户）

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | bigint | PK | 用户内部 ID |
| uid | string | unique, not null | 用户公开 UID |
| username | string | unique, not null | 用户名 |
| password_hash | string | not null | 密码哈希 |
| email | string | nullable | 邮箱 |
| created_at | datetime | not null | 创建时间 |

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | uuid / bigint | PK | 角色 ID |

| description | text | nullable | 角色描述 |
| created_at | datetime | not null | 创建时间 |
