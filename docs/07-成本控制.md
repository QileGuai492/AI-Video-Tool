# 07 - 成本控制

> 状态：已评审  
> 最近更新：2026-01-01  
> 所属文档库：[README](../README.md)

## 1. 成本控制原则

1. 优先使用有免费额度或按量付费便宜的 API。
2. 质量优先时再切换到高价模型。
3. 所有成本可记录、可查询、可预估。
4. 能本地免费完成的后处理，不依赖付费云服务。

## 2. 成本估算参考

| 环节 | 参考成本 | 说明 |
| --- | --- | --- |
| 文生图（首帧） | ¥0.1~0.5 / 张 | 可大幅减少视频废片。 |
| 视频生成（默认 720p/5s） | ¥0.5~2 / 次 | 默认档位。 |
| 视频生成（高质量 1080p/5s） | ¥1~3 / 次 | 高质量档位。 |
| 60 秒成片 | ¥5~30 / 条 | 需 6~12 个片段。 |
| 后处理（本地 FFmpeg） | ¥0 | 本地免费。 |
| 后处理（云端 GPU，可选） | ¥1~2 / 小时 | 如 AutoDL 临时租用。 |

## 3. 成本控制策略

| 策略 | 说明 |
| --- | --- |
| API 选型 | 优先免费额度或低价 API；质量优先时切换高价模型。 |
| 首帧生成 | 先用低成本文生图生成首帧，减少视频废片。 |
| 质量档位 | 快速 / 标准 / 高质量三档，默认标准。 |
| 缓存与复用 | 历史生成视频可复用，避免重复生成。 |
| 任务前估算 | 提交任务时返回 `estimated_cost`。 |
| 任务后记账 | 每次 API 调用记录费用，汇总到任务成本。 |
| 成本上限 | 用户可设置 `cost_limit`，超出时拦截或提示。 |

## 4. 成本记录字段

建议在 `generation_logs` 或 `video_tasks.cost` 中记录：

- 模型名称
- 调用类型（image / video / tts / llm / bgm）
- 输入参数摘要
- 实际费用
- 耗时
- 是否重试
