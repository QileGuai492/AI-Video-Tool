## 1. 验证目标

验证白模降级流水线在真实模型提供商环境下可用：

```text
白模视频 → 按镜头抽帧 → 逐镜头图生视频 → 拼接成片
```

## 2. 使用提供商

当前使用 **Agnes AI**（免费全模态 API）：

```env
AGNES_API_KEY=sk-...
AGNES_BASE_URL=https://apihub.agnes-ai.com/v1
PUBLIC_BASE_URL=https://你的公网地址
```

> `PUBLIC_BASE_URL` 必须是对外可访问的地址，例如 cpolar / ngrok / 服务器域名，
> 否则 Agnes 无法访问本地生成的白模关键帧图片。
