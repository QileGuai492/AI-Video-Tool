## 1. 验证目标

验证白模降级流水线在真实模型提供商环境下可用：

```text
白模视频 → 按镜头抽帧 → 逐镜头图生视频 → 拼接成片
```

## 2. 使用提供商

当前使用 **Agnes AI**（免费全模态 API）：

```env
AGNES_API_KEY=sk-...
AGNES_BASE_URL=https://apihub.agnes-ai.com/v1
PUBLIC_BASE_URL=https://你的公网地址
```

> `PUBLIC_BASE_URL` 必须是对外可访问的地址，例如 cpolar / ngrok / 服务器域名，
> 否则 Agnes 无法访问本地生成的白模关键帧图片。

## 3. 执行验证

```bash
# 推荐在 API 容器内执行，保证 uploads 与公网 URL 指向同一存储
docker compose exec api python scripts/validate_real_previs.py

# 60 秒拼接验证（Mock 片段，无外部费用）
docker compose exec api python scripts/validate_stitch_60s.py

# 真实角色一致性验证（Agnes 文生图 + 多镜头视频生成）
docker compose exec api python scripts/validate_real_character_consistency.py

# 字幕叠加验证（FFmpeg 烧录 SRT 到视频）
docker compose exec api python scripts/validate_subtitle_overlay.py

# 真实 VLM 质量评估验证（Agnes 视觉模型对首帧打分）
docker compose exec api python scripts/validate_real_quality_vlm.py

# 真实文字生成白模验证（Agnes LLM 生成场景 JSON）
docker compose exec api python scripts/validate_real_previs_generate.py
```

> 宿主机直接运行会因宿主机 `uploads/` 与 Docker 卷不一致而失败。

## 5. 注意事项

- TTS 已切换为 Edge TTS（免费），不再依赖 SiliconFlow；SiliconFlow 的 402 不再影响任务。
- Agnes 视频接口有频率限制（约 1 次/分钟），连续多镜头时需要注意。
- Agnes 生成结果需要公网可访问的 `PUBLIC_BASE_URL`。
