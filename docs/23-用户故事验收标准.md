# 23 - 用户故事验收标准

> 状态：待评审  
> 最近更新：2026-01-01  
> 所属文档库：[README](../README.md)

## 1. 目的

为每条用户故事补充可验证的验收条件，便于开发、测试和 Demo 验收。

## 2. US-1 一句话成片

**作为创作者，我希望输入“一只猫在雨天奔跑”后，系统能自动优化提示词、生成首帧、生成视频、配上雨声音效和背景音乐，并输出可直接发布的视频。**

### 验收条件

- [ ] 输入一句话后，系统返回优化后的提示词。
- [ ] 系统自动生成首帧。
- [ ] 系统生成至少 1 个视频片段。
- [ ] 系统自动生成配音 / 解说。
- [ ] 系统自动匹配或生成 BGM。
- [ ] 最终输出 MP4 文件，可在线预览和下载。
- [ ] 整个流程可通过调度 Agent 一键启动。

## 3. US-2 角色一致性

**作为创作者，我希望上传我的角色照片后，后续所有生成的视频片段中该角色外貌一致，即使跨多个对话任务也能保持一致。**

### 验收条件

- [ ] 用户可上传角色参考图并保存到角色库。
- [ ] 同一任务内多个片段中角色外观一致（人工或自动评估）。
- [ ] 用户选择“跨对话保持角色一致”后，新任务能自动使用该角色特征。
- [ ] 角色一致性评分低于阈值时自动重试。

## 4. US-3 自定义比例与拼接

**作为创作者，我希望选择视频比例为 9:16，并生成 60 秒的短视频，系统自动拼接成片。**

### 验收条件

- [ ] 用户可选择 16:9、9:16、1:1。
- [ ] 用户可选择目标时长。
- [ ] 系统自动计算分段数量。
- [ ] 自动拼接后总时长与目标时长误差 ≤ 5 秒。
- [ ] 片段间有基本转场，无明显黑屏。

## 5. US-4 自动字幕

**作为创作者，我希望能为视频添加自动生成的字幕，且文字清晰无乱码。**

### 验收条件

- [ ] 系统可根据 TTS 文本或语音识别生成字幕。
- [ ] 字幕可叠加到视频中。
- [ ] 字幕文字清晰，无乱码、无截断。
- [ ] 用户可选择开启 / 关闭字幕。

## 6. US-5 成本估算与质量档位

**作为创作者，我希望看到每次生成任务的花费估算，并能选择不同质量档位控制成本。**

### 验收条件

- [ ] 提交前展示成本估算。
- [ ] 用户可选择快速 / 标准 / 高质量。
- [ ] 生成完成后展示最终成本。
- [ ] 成本记录可查询。
- [ ] 达到用户成本上限时阻止提交或强提醒。

## 7. US-6 历史与模板

**作为创作者，我希望能保存我的历史记录和常用模板，下次快速复用。**

### 验收条件

- [ ] 历史任务列表可查看，支持分页。
- [ ] 历史任务可查看详情和下载成片。
- [ ] 用户可保存当前参数为模板。
- [ ] 模板列表可查看，点击模板可回填创作页参数。
