# 06 - API 设计

> 状态：已评审  
> 最近更新：2026-01-01  
> 所属文档库：[README](../README.md)

## 1. 通用约定

- Base URL：`/api/v1`（建议统一前缀，便于版本管理）。
- 认证方式：JWT Bearer Token。
- 请求与响应均使用 JSON。
- 错误响应统一格式：

```json
{
  "code": "ERROR_CODE",
  "message": "人类可读错误信息",
  "details": {}
}
```

## 3. 示例：注册 / 登录

### 注册

```http
POST /api/v1/auth/register
Content-Type: application/json
```

```json
{
  "username": "creator",
  "password": "secret123",
  "email": "creator@example.com"
}
```

### 登录

```http
POST /api/v1/auth/login
Content-Type: application/json
```

```json
{
  "username": "creator",
  "password": "secret123"
}
```

```json
{
  "access_token": "<JWT>",
  "token_type": "bearer",
  "expires_in": 86400
}
```

## 8. 补充接口

### 8.1 上传文件

```http
POST /api/v1/upload
Authorization: Bearer <JWT>
Content-Type: multipart/form-data
```

参数：

- `file`：文件
- `file_type`：`image` / `audio` / `video`

响应：

```json
{
  "file_url": "https://oss.example.com/files/xxx.png",
  "file_type": "image",
  "size": 204800
}
```

### 8.2 取消任务

```http
POST /api/v1/generate/{task_id}/cancel
Authorization: Bearer <JWT>
```

响应：

```json
{
  "task_id": "uuid",
  "status": "cancelled"
}
```

### 8.3 重试任务

```http
POST /api/v1/generate/{task_id}/retry
Authorization: Bearer <JWT>
```

响应：

```json
{
  "task_id": "uuid",
  "status": "queued"
}
```

### 8.4 查询任务成本

```http
GET /api/v1/cost/task/{task_id}
Authorization: Bearer <JWT>
```

响应：

```json
{
  "task_id": "uuid",
  "total_cost": 12.5,
  "items": [
    {
      "provider": "minimax",
      "call_type": "video",
      "cost": 8.0,
      "created_at": "2026-01-01T00:00:00Z"
    }
  ]
}
```

### 8.5 分页与筛选

列表接口统一支持：

- `page`：页码，默认 1。
- `page_size`：每页数量，默认 20，最大 100。
- `status`：按状态筛选。
- `created_from` / `created_to`：时间范围。

示例：

```http
GET /api/v1/history?page=1&page_size=20&status=completed
```

### 8.6 下载视频

```http
GET /api/v1/generate/{task_id}/download
Authorization: Bearer <JWT>
```

- 本地存储：返回 MP4 文件。
- OSS / 远程 URL：重定向到文件地址。

## 9. 错误码表

| 错误码 | 含义 | HTTP 状态 |
| --- | --- | --- |
| `INVALID_PARAMETER` | 参数错误 | 400 |
| `UNAUTHORIZED` | 未认证 / 无权限 | 401 |
| `TASK_NOT_FOUND` | 任务不存在 | 404 |
| `API_TIMEOUT` | 外部 API 超时 | 502 |
| `API_RATE_LIMITED` | 外部 API 限流 | 429 |
| `API_SERVER_ERROR` | 外部 API 5xx | 502 |
| `API_QUOTA_EXCEEDED` | 余额 / 配额不足 | 402 |
| `CONTENT_REJECTED` | 内容被拒绝 | 422 |
| `INTERNAL_ERROR` | 系统内部错误 | 500 |

## 10. 任务状态机

```text
pending → optimizing_prompt → generating_first_frame
       → generating_video → generating_audio → generating_subtitle
       → post_processing → quality_check → completed
                                              ↘ failed（可重试）
```

状态说明：

| 状态 | 说明 |
| --- | --- |
| pending | 已创建，等待调度 |
| optimizing_prompt | 正在优化提示词 |
| generating_first_frame | 正在生成首帧 |
| generating_video | 正在生成视频片段 |
| generating_audio | 正在生成配音 / BGM |
| generating_subtitle | 正在生成字幕 |
| post_processing | 正在拼接 / 后处理 |
| quality_check | 正在进行质量评估 |
| completed | 已完成 |
| failed | 失败，可重试 |

## 11. 版本与兼容

- 破坏性变更时新增 `/api/v2`，不修改旧版本。
- 新增字段时保持向后兼容，旧客户端忽略未知字段。
