# 08 - 风险与依赖管理

> 状态：已评审  
> 最近更新：2026-01-01  
> 所属文档库：[README](../README.md)

## 1. 风险矩阵

| 风险 | 影响 | 概率 | 应对措施 |
| --- | --- | --- | --- |
| API 服务商政策变动 / 涨价 | 成本上升或不可用 | 高 | 多模型集成，动态切换。 |
| 角色一致性效果不佳 | 跨视频角色差异大 | 高 | 采用“多角度参考图 + 图生视频 + 首帧控制”组合策略；后续可微调开源模型。 |
| 视频拼接后转场生硬 | 观感差 | 中 | 使用 FFmpeg 渐变转场，或预留 1 秒重叠进行溶解。 |
| 生成时间过长 | 用户体验差 | 中 | 异步任务 + 进度提示；可分段并行生成。 |
| 版权与合规风险 | 发布到平台可能被下架 | 中 | 使用授权音乐库，标注 AI 生成；不生成侵权内容。 |
| 国内 API 对个人申请限制 | 部分高质量 API 难以获取 | 中 | 优先申请 MiniMax、通义万相；可灵 / 火山若受限，用开源模型云端部署替代。 |

## 2. 外部依赖清单

| 依赖 | 用途 | 替代方案 |
| --- | --- | --- |
| MiniMax 海螺 | 视频生成、TTS | 火山引擎、可灵 |
| 通义万相 | 文生图 | Flux、SD |
| Claude API | 提示词优化、台词生成 | GPT-4o-mini、Qwen |
| Whisper | 语音识别 / 字幕 | 直接使用 TTS 文本生成字幕 |
| FFmpeg / MoviePy | 拼接、字幕、转码 | 云端转码服务 |
| 阿里云 OSS | 文件存储 | 本地磁盘、其他对象存储 |

## 3. 风险应对流程

1. 风险发生时先评估影响范围。
2. 优先使用替代 provider 或本地方案。
3. 更新 `04-技术架构.md` 中的适配层与配置。
4. 重大变更记录到 `docs/adr/`。

## 4. 合规红线

- 不使用未经授权的音乐素材。
- 不生成侵权、违法或违规内容。
- 发布内容标注 AI 生成。
- 个人使用阶段自己把控合规，后续多用户阶段再引入审核系统。
