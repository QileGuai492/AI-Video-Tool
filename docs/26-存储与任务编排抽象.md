> 状态：已实现  
> 最近更新：2026-01-01

## 1. 目的

定义两个核心扩展点：

1. **存储抽象**：让本地磁盘与阿里云 OSS 可切换。
2. **任务编排抽象**：让 Sprint 1 的直写流水线可平滑替换为 LangGraph。

## 2. 存储抽象（StorageProvider）

### 2.1 接口

```python
class StorageProvider(Protocol):
    def upload(self, content: bytes, suffix: str, folder: str = "files") -> str: ...
    def get_url(self, key: str) -> str: ...
```

- `upload`：上传文件，返回文件 key。
- `get_url`：根据 key 返回可访问 URL。

### 2.2 实现

| 实现 | 说明 |
| --- | --- |
| `LocalStorageProvider` | 保存到 `uploads/`，URL 为 `/uploads/...` |
| `OSSStorageProvider` | 上传到阿里云 OSS，支持公共域名或签名 URL |

### 2.3 配置

```dotenv
STORAGE_BACKEND=local   # local / oss
OSS_ACCESS_KEY_ID=
OSS_ACCESS_KEY_SECRET=
OSS_BUCKET=
OSS_ENDPOINT=
OSS_PUBLIC_BASE_URL=
```

### 2.4 使用方式

```python
from app.storage import storage

key = storage.upload(content=content, suffix="png", folder="images")
url = storage.get_url(key)
```

## 3. 任务编排抽象（TaskOrchestrator）

### 3.1 接口

```python
class TaskOrchestrator(Protocol):
    def run(self, task_id: int) -> None: ...
```

### 3.2 当前实现

`SimpleTaskOrchestrator` 执行顺序流水线：

```text
优化提示词 → 生成首帧 → 生成多个视频片段 → 标记完成
```

### 3.3 后续替换

Sprint 4 接入 LangGraph 时，新增 `LangGraphOrchestrator` 并实现 `run(task_id)`，然后在 `app/orchestration/factory.py` 中根据配置切换即可。

Celery 任务 `process_video_task` 不感知具体编排器。
