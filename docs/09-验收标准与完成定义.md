# 09 - 验收标准与完成定义

> 状态：已评审  
> 最近更新：2026-08-23  
> 所属文档库：[README](../README.md)

## 1. Demo 验收标准

- [ ] 用户可登录并进入创作界面。
- [ ] 输入一句话或上传图片后，系统能自动优化提示词、生成首帧、生成视频、拼接成片（默认 60 秒，16:9）。
- [ ] 上传角色参考图后，同一任务内多个片段角色外观一致。
- [ ] 视频包含自动生成的配音、BGM 和字幕，文字清晰无乱码。
- [ ] 用户可选择视频比例、时长、质量档位，并看到成本估算。
- [ ] 生成历史可查看，视频可在本地或 OSS 下载。
- [ ] 整个流程可通过调度 Agent 一键启动，支持失败重试。

## 2. 功能完成定义（Definition of Done）

每个需求 / 用户故事完成时，必须满足：

- [ ] 代码已提交，包含必要测试。
- [ ] API 文档已同步更新（`06-接口设计.md`）。
- [ ] 数据模型变更已同步（`05-数据模型.md`）。
- [ ] 关键配置可复用（`.env.example`）。
- [ ] 本地运行通过，能完成对应 Demo 演示。
- [ ] 成本记录与错误日志可查询。

## 3. Sprint 完成定义

- [ ] 本 Sprint 承诺范围已实现并通过验收。
- [ ] 未完成项已回到 Product Backlog 并重新排优先级。
- [ ] 相关文档已更新。
- [ ] 可向本人 / 协作方进行 Demo。
