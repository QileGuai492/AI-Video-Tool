## 1. 目标

定义前端页面结构、用户操作流程和任务进度展示方式。MVP 阶段可用 Streamlit 快速验证，后续替换为 React。

## 2. 页面结构

```text
/
├── 登录 / 注册
├── 创作页（首页）
│   ├── 提示词输入
│   ├── 角色选择 / 上传
│   ├── 参数设置（比例、时长、质量、模型）
│   ├── 成本估算
│   └── 生成按钮
├── 任务详情 / 进度页
├── 历史记录
├── 角色库
└── 模板库
```

## 3. 核心用户流程

```text
登录
  → 进入创作页
  → 输入一句话 / 上传图片 / 选择角色
  → 设置比例、时长、质量
  → 查看成本估算
  → 点击“开始生成”
  → 跳转任务进度页
  → 实时看到阶段进度
  → 完成后预览 / 下载
```

## 4. 任务进度展示

建议使用 **轮询**（MVP 简单可靠），后续可升级为 SSE / WebSocket。

### 4.1 轮询方案

- 每 3~5 秒调用 `GET /generate/status/{task_id}`。
- 展示：
  - 当前阶段
  - 完成百分比
  - 已完成片段数 / 总片段数
  - 当前累计成本
  - 预计剩余时间（可选）

### 4.2 升级方案

- SSE：服务端主动推送状态变化。
- WebSocket：适合实时日志、取消操作。

## 5. 成本展示

- 提交前：根据参数估算成本。
- 生成中：实时累计成本。
- 完成后：最终成本。
- 超过用户 `cost_limit` 时：阻止提交或强提醒。

## 6. 页面与 API 映射

| 页面 | 主要 API |
| --- | --- |
| 登录 / 注册 | `/auth/login`、`/auth/register` |
| 创作页 | `/generate/video`、`/characters`、`/templates` |
| 任务进度页 | `/generate/status/{task_id}`、`/generate/{task_id}/cancel` |
| 历史记录 | `/history` |
| 角色库 | `/characters` |
| 模板库 | `/templates` |

## 7. MVP（Streamlit）页面划分

> 状态：**已实现**，入口为 `streamlit_app.py`。

- `streamlit_app.py`：登录 / 注册 + 创作页 + 任务进度 + 历史记录 + 角色库 + 音频/字幕 + 成本（单文件实现）。
- 角色库支持：创建角色、查看详情、添加多角度参考图。
- 创作页支持：选择角色后携带 `character_id` 提交生成任务。
- 音频/字幕页支持：TTS 配音、BGM、字幕生成。
- 成本页支持：成本汇总、任务成本明细查询。
