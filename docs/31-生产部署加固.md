## 1. HTTPS

### 1.1 配置文件

- `deploy/nginx.conf`：HTTP 反向代理
- `deploy/nginx-ssl.conf`：HTTPS 反向代理示例

### 1.2 使用 Certbot

```bash
# 安装 Certbot
apt install certbot python3-certbot-nginx

# 申请证书（需域名已解析到服务器）
certbot --nginx -d example.com

# 将证书挂载到 Nginx 容器
# docker-compose 中 nginx 服务增加：
#   - ./deploy/nginx-ssl.conf:/etc/nginx/conf.d/default.conf:ro
#   - /etc/letsencrypt:/etc/nginx/certs:ro
```

## 2. OSS 存储

### 2.1 配置

`.env`：

```env
STORAGE_BACKEND=oss
OSS_ACCESS_KEY_ID=your_id
OSS_ACCESS_KEY_SECRET=your_secret
OSS_BUCKET=your_bucket
OSS_ENDPOINT=oss-cn-shanghai.aliyuncs.com
OSS_PUBLIC_BASE_URL=https://your-bucket.oss-cn-shanghai.aliyuncs.com
```

### 2.2 切换后注意

- 所有上传、生成文件都会写入 OSS。
- `video_url` 返回 OSS 公网地址。
- 下载接口会对 OSS URL 直接重定向。
- 需要在 OSS Bucket 设置公共读或使用签名 URL。

## 3. 监控

### 3.1 当前已有

- `GET /api/v1/metrics`：返回用户数、任务状态、生成日志数。
- Flower：Celery 任务监控。

### 3.2 建议接入

- Prometheus 采集 `/api/v1/metrics`。
- Grafana 展示任务成功率、队列长度、API 延迟。
- 告警规则：
  - 任务失败率 > 10%
  - Celery 队列积压 > 100
  - 磁盘使用率 > 80%

## 4. 备份

脚本：`deploy/backup.sh`

```bash
./deploy/backup.sh /data/backups
```

备份内容：

- PostgreSQL 全量 SQL 备份
- `uploads/` 上传文件压缩包

建议：

- 每日自动备份
- 备份保留 7 天
- 异地存储一份

## 5. 日志采集

当前日志为结构化文本输出到 stdout。

建议：

- Docker 使用 `json-file` 或 `fluentd` 驱动收集。
- 接入 Loki / ELK 做集中查询。
- 按 `timestamp`、`level`、`logger` 建立索引。

## 6. 安全加固

- 修改默认 `SECRET_KEY`、`JWT_SECRET`、数据库密码。
- Nginx 限制上传大小。
- 生产环境关闭 `DEBUG=true`。
- 为管理接口增加认证/内网访问控制。
