## 1. Sprint 1（2 周）：MVP 核心链路

> 状态：**已实现（Mock 模式）**，可本地运行 Demo；真实 API Key 就绪后切换 Provider 即可。

**目标**：跑通“提示词 → 首帧 → 单段视频 → 下载”。

### 范围

- 搭建 FastAPI 后端 + React 前端（`frontend/`）。
- 用户注册 / 登录（JWT）。
- 集成 1 家视频生成 API（MiniMax Provider 已实现，未配置 Key 时回退 Mock）。
- 集成 1 家文生图 API（通义万相 Provider 已实现，未配置 Key 时回退 Mock）。
- 提示词优化（Claude Provider 已实现，未配置 Key 时回退 Mock）。
- 任务提交与结果查询（Celery + 异步轮询）。
- 视频保存到本地或阿里云 OSS（通过 StorageProvider 抽象）。

### 交付物

- 能通过网页输入提示词，生成一个 5 秒视频并下载。

### 验收要点

- [x] 用户可注册 / 登录。
- [x] 输入提示词后自动优化。
- [x] 生成首帧。
- [x] 生成 5 秒视频并可下载。

## 2. Sprint 2（2 周）：角色一致性与多片段拼接

> 状态：**开发中**（已实现角色多角度参考图、任务关联角色、视频拼接服务）

**目标**：支持角色参考图，生成多个片段并拼接成 60 秒视频。

### 范围

- 新增“角色库”：上传参考图，存储角色特征（可选生成多角度参考图）。
- 集成图生视频 API，将首帧 + 角色参考图传入，保持一致性。
- 开发“视频拼接”模块：使用 FFmpeg 将多个片段按顺序拼接，支持简单转场。
- 支持用户指定视频比例和时长（默认 16:9，60 秒，分段数量自动计算）。

### 交付物

- 上传角色图，生成 3-4 个片段，自动拼接为 1 分钟视频。

### 验收要点

- [x] 可上传角色参考图。
- [x] 支持添加角色多角度参考图。
- [ ] 同一任务内多个片段角色外观一致（真实 Provider 接入后验证）。
- [ ] 自动拼接为 60 秒成片（拼接服务已实现，Mock 片段为占位文件）。
- [x] 支持 16:9 / 9:16 / 1:1 比例选择。

## 3. Sprint 3（2 周）：音频与字幕

> 状态：**开发中**（已实现 TTS / BGM / 字幕接口骨架，使用 Mock Provider）

**目标**：自动生成配音、BGM，添加字幕。

### 范围

- 集成 TTS API（如 MiniMax TTS、阿里云语音合成、SiliconFlow），支持多音色。
- 开发“音频 Agent”：根据视频内容生成台词文本（调用 LLM），或用户手动输入台词；调用 TTS 生成音频。
- BGM 选择：集成免费音乐库 API 或本地音乐文件，由 AI 根据视频标签推荐；用户可手动选择 / 上传。
- 字幕生成：使用 Whisper 自动识别（如果视频中有语音），或直接根据 TTS 文本生成字幕文件，用 MoviePy / FFmpeg 叠加到视频（解决文字乱码）。

### 交付物

- 生成的视频包含配音、背景音乐和清晰字幕，可直接发布。

### 验收要点

- [x] 提供 TTS 音频生成接口（Mock 可返回结果）。
- [x] 提供 BGM 音频生成接口。
- [x] 提供字幕生成接口（SRT）。
- [ ] 自动生成配音并可手动替换（真实 TTS 接入后验证）。
- [ ] 可自动推荐 / 手动选择 BGM（曲库完善后验证）。
- [ ] 字幕清晰无乱码（叠加到视频后验证）。

## 4. Sprint 4（2 周）：调度 Agent 与质量增强

> 状态：**开发中**（已实现 LangGraph 编排器骨架、质量评估基础、成本接口）

**目标**：引入 LangGraph 调度 Agent，自动化工作流，支持质量评估与重试。

### 范围

- 将现有流程重构为 LangGraph 图（节点：PromptAgent、ImageAgent、VideoGenAgent、AudioAgent、SubtitleAgent、PostProcessAgent、QualityCheckAgent）。
- 实现 QualityCheckAgent：调用视觉语言模型对视频首帧 / 片段截图打分，低于阈值自动重试或更换模型。
- 后处理增强：可选接入 Real-ESRGAN 超分、RIFE 插帧（云端 GPU 或纯 CPU 方案），提升清晰度和流畅度。
- 成本估算模块：记录每次 API 调用费用，展示单次生成成本。

### 交付物

- 一个完整的多 Agent 自动视频生成流水线，质量可控、成本透明。

### 验收要点

- [x] 一键启动完整流水线（Simple / LangGraph 两种编排器）。
- [x] 失败可自动重试（Celery autoretry + TaskRetry 记录）。
- [x] 展示成本估算与最终成本（`estimated_cost` + `/cost` 接口）。

## 5. Sprint 5（持续）：优化与扩展

### 范围

- 多模型集成：增加火山引擎（即梦同源）、可灵 API，由调度 Agent 根据风格自动选择。
- 视频比例、分辨率、时长自定义优化。
- 移动端适配（用 React 重写前端，或开发小程序）。
- 数据分析：记录用户操作、生成偏好，用于 BGM 推荐智能优化。
- 模板系统：保存常用设置和提示词模板。

### 交付物

- 持续迭代版本，按优先级从 Product Backlog 拉取。

## 6. Sprint 节奏约定

- 每个 Sprint 2 周。
- Sprint 开始前从 `02-需求与用户故事.md` 拉取需求，确认范围。
- Sprint 结束时对照本文件“验收要点”进行 Demo。
- 未完成项自动回到 Product Backlog，重新排优先级。
