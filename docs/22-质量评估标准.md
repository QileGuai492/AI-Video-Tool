# 22 - 质量评估标准

> 状态：已实现启发式 + 可选 VLM  
> 最近更新：2026-08-23  
> 所属文档库：[README](../README.md)

## 1. 目的

定义 QualityCheckAgent 的评估维度、打分方式、阈值和重试策略，让“质量”可量化、可自动判断。

## 2. 评估对象

- 首帧图片。
- 每个视频片段的抽帧（建议每个片段抽 3~5 帧）。
- 最终成片的封面 / 关键帧。

## 3. 评估维度

| 维度 | 说明 | 权重 |
| --- | --- | --- |
| 画面清晰度 | 是否模糊、噪点、变形 | 20% |
| 构图合理性 | 主体是否完整、布局是否协调 | 15% |
| 文本 / 字幕清晰度 | 是否乱码、遮挡、截断 | 15% |
| 角色一致性 | 与参考图是否一致 | 25% |
| 动作流畅度 | 是否有明显跳变、形变 | 15% |
| 内容匹配度 | 是否匹配用户提示词 | 10% |

## 4. 打分方式

- 使用视觉语言模型（GPT-4V / Qwen-VL / Agnes Vision）对图片进行 0~10 分打分。
- 每个维度返回分数和简短理由。
- 最终分数 = 加权平均。
- 当前已接入 Agnes 视觉语言模型（通过 `chat/completions` 的 `image_url`）对视频首帧打分；设置 `QUALITY_VLM_ENABLED=true` 后，LangGraph 编排器会自动使用该链路，失败时回退启发式评估。

```json
{
  "overall_score": 8.2,
  "dimensions": {
    "clarity": 9.0,
    "composition": 8.0,
    "subtitle": 8.5,
    "character_consistency": 7.5,
    "motion": 8.0,
    "content_match": 8.5
  },
  "reason": "角色侧面略有变化，其余良好"
}
```

## 5. 阈值

| 等级 | 分数 | 处理 |
| --- | --- | --- |
| 通过 | ≥ 7.5 | 进入下一步 |
| 边缘 | 6.0 ~ 7.4 | 记录，可人工确认或自动重试一次 |
| 不通过 | < 6.0 | 自动重试或更换模型 |

## 6. 重试策略

- 同一阶段最多重试 2 次。
- 每次重试可：
  - 更换提示词。
  - 更换模型 / Provider。
  - 重新生成首帧。
- 重试仍不通过时，任务标记 `failed_final`，保留失败原因。

## 7. 人工介入

- 当“边缘”分数出现时，可在前端提示用户确认是否接受。
- 用户确认接受后，任务继续。
- 用户拒绝后，可选择重试或取消。

## 8. 成本控制

- 质量评估本身也有 API 成本。
- 建议每个片段抽帧不超过 5 张。
- 对最终成片只评估一次封面 + 1~2 个关键帧。
