# 30 - 前端优化方案

> 状态：待评审  
> 最近更新：2026-08-21  
> 所属文档库：[README](../README.md)

## 1. 目标

将当前 Streamlit MVP 前端升级为 **React + TypeScript + Vite + Three.js** 的正式前端，支撑白模预演、任务中心、模板市场、成本中心等完整创作工作流。

## 2. 现状问题

- 单页表单式交互，缺少复杂创作工具。
- 没有白模 3D 编辑器。
- 任务进度需要手动刷新。
- 批量任务没有聚合面板。
- 没有视频对比预览。
- 模板市场只是列表，不是卡片式浏览。
- 图片上传能力刚补上，但整体 UI 仍偏验证性质。

## 3. 技术选型

| 层 | 选型 | 说明 |
| --- | --- | --- |
| 框架 | React 18 + TypeScript | 生态成熟 |
| 构建 | Vite | 开发体验好 |
| UI | Ant Design 5 | 中后台组件丰富 |
| 状态 | Zustand | 轻量 |
| 3D | Three.js + @react-three/fiber | 白模灰模编辑器 |
| 视频 | Video.js / Plyr | 多视频对比播放 |
| 路由 | React Router 6 | 页面路由 |
| HTTP | Axios / TanStack Query | 请求与缓存 |

## 4. 页面规划

| 页面 | 功能 |
| --- | --- |
| 工作台 | 文案输入、角色/场景参考图、白模预演、镜头脚本 |
| 任务中心 | 任务列表、进度、批量、取消/重试、下载 |
| 模板市场 | 分类、搜索、卡片、复制 |
| 成本中心 | 余额、明细、趋势 |
| 设置 | API Key、默认模型、存储配置 |

## 5. 核心组件

### 5.1 PrevisCanvas（3D 白模画布）

- 基于 Three.js / react-three-fiber。
- **第一版重点：自由建模 + 关键帧动画**
  - 添加方块/圆柱/球体/平面/灰模人形。
  - 对象选择、移动、旋转、缩放。
  - 位置/旋转/缩放关键帧。
  - 相机自由运镜 + 相机路径关键帧。
  - 播放/暂停/拖动时间轴。
- 简单模式：
  - 选择模板。
  - 调整角色站位。
  - 设置相机路径。
- 高级模式：
  - 自由建模与关键帧。
  - 镜头切分。
  - 导入/导出场景 JSON。
- 支持预览白模动画。
- 文字自动生成白模为后一期功能。

### 5.2 TimelineEditor（分镜时间轴）

- 按镜头展示。
- 每镜头可设置：
  - 时长
  - 景别
  - 相机运动
  - 角色动作
  - 文字/对白
- 支持拖拽调整顺序。

### 5.3 VideoCompare（多视频对比）

- 并排展示：
  - 参考图
  - 白模视频
  - AI 成片
- 支持同步播放/暂停。

### 5.4 TaskProgressBoard（任务进度面板）

- 展示单个任务阶段进度。
- 展示批量任务聚合进度。
- 支持取消/重试。

## 9. 实施路线

| 阶段 | 内容 | 优先级 |
| --- | --- | --- |
| Phase 1 | React 项目骨架、登录、任务中心 | P0 |
| Phase 2 | 工作台：文案 + 参考图上传 + 角色选择 | P0 |
| Phase 3 | Three.js 白模编辑器（自由建模 + 关键帧动画） | P0 |
| Phase 4 | 白模接口与前端同步联调 | P0 |
| Phase 5 | 分镜时间轴、任务进度、批量面板 | P1 |
| Phase 6 | 模板市场、成本中心、设置 | P1 |
| Phase 7 | 文字自动生成白模（后一期） | P2 |

## 10. 验收标准

- 用户可以在浏览器中完成“白模搭建 → 渲染 → 提交生成 → 成片”的完整流程。
- 白模编辑器支持自由建模、关键帧动画和相机运镜。
- 白模编辑器同时保留简单模式（模板）与高级模式。
- 任务中心支持实时进度和批量聚合。
- 模板市场支持浏览和复制。
- 前端与后端 API 完全打通。
- 文字自动生成白模作为后一期验收项。
