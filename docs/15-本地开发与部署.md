## 1. 目的

定义本地开发环境、容器化部署、数据库迁移、日志与备份方案，保证从“个人电脑”到“阿里云 ECS”可复现。

## 2. 本地开发环境

### 2.1 必需依赖

- Python 3.11+
- Node.js 18+（后续前端）
- Docker / Docker Compose
- FFmpeg
- Git

### 2.2 快速启动（建议）

```bash
# 1. 克隆 / 进入项目
cd ai-video-tool

# 2. 创建虚拟环境
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate

# 3. 安装依赖
pip install -r requirements-dev.txt

# 4. 配置环境变量
cp .env.example .env
# 编辑 .env 填入真实 Key

# 5. 启动基础服务（Redis / PostgreSQL）
docker compose up -d redis postgres

# 6. 运行数据库迁移
alembic upgrade head

# 7. 启动后端
uvicorn app.main:app --reload

# 8. 启动 Worker
celery -A app.tasks.celery_app worker --loglevel=info

# 9. 启动 Streamlit 前端（可选）
streamlit run streamlit_app.py
```

## 3. Docker 容器化部署

当前项目已包含：

- `Dockerfile`：Python 3.11 + FFmpeg，安装 FastAPI / Celery / Streamlit 等依赖
- `.dockerignore`：排除本地缓存、密钥、测试文件
- `docker-compose.yml`：一键启动完整环境

### 服务组成

| 服务 | 说明 | 端口 |
| --- | --- | --- |
| api | FastAPI 后端 | 8000 |
| worker | Celery Worker | - |
| streamlit | Streamlit 前端 | 8501 |
| redis | 队列 / 缓存 | 6379 |
| postgres | PostgreSQL 数据库 | 5432 |
| flower | Celery 任务监控 | 5555 |
| nginx | Nginx 反向代理 | 80 |

Nginx 配置位于 `deploy/nginx.conf`，生产环境可在此基础上增加 HTTPS 证书与域名。

### 构建与启动

```bash
# 构建镜像
docker compose build

# 启动全部服务
docker compose up -d

# 查看状态
docker compose ps

# 查看日志
docker compose logs -f api
docker compose logs -f worker
docker compose logs -f streamlit

# 停止
docker compose down
```

### 首次部署迁移

```bash
docker compose exec api alembic upgrade head
```

### 访问地址

- 后端 API：`http://localhost:8000`
- Streamlit 前端：`http://localhost:8501`
- Flower 监控：`http://localhost:5555`

## 4. 数据库迁移

- 使用 Alembic 管理迁移。
- 每次数据模型变更生成新迁移文件：

```bash
alembic revision --autogenerate -m "描述"
alembic upgrade head
```

- 禁止手动改生产库结构。

## 5. 部署流程（阿里云 ECS）

建议流程：

```text
本地提交代码
→ GitHub / GitLab 触发 CI
→ 构建 Docker 镜像并推送到镜像仓库
→ ECS 拉取镜像
→ docker compose up -d
→ 执行数据库迁移
→ 健康检查
```

### 部署检查清单

- [ ] `.env` 已在服务器配置，不进入 Git。
- [ ] Nginx 配置 HTTPS。
- [ ] 数据库数据卷已挂载并定期备份。
- [ ] Redis 持久化策略已配置。
- [ ] 日志已落到文件或采集系统。
- [ ] 首次部署执行 `alembic upgrade head`。

## 6. 日志与监控

- 应用日志统一输出 JSON，包含 `task_id`、`stage`、`provider`、`cost`。
- 建议接入：

  - 结构化日志：Python `logging` + JSON Formatter。
  - 任务监控：Flower。
  - 错误追踪：Sentry（可选）。
  - 指标：Prometheus + Grafana（后续扩展）。

## 7. 备份策略

| 数据 | 频率 | 保留 |
| --- | --- | --- |
| PostgreSQL | 每日全量 + WAL | 7 天 |
| OSS 文件 | 按生命周期策略 | 30 天 |
| `.env` | 加密备份到安全位置 | 长期 |
| 配置 / 迁移文件 | Git 管理 | 长期 |

## 8. 环境划分

| 环境 | 用途 | 数据库 | 外部 API |
| --- | --- | --- | --- |
| local | 本地开发 | SQLite / Docker PostgreSQL | Mock 或真实测试 Key |
| dev | 开发联调 | PostgreSQL | 测试 Key / 低额度 |
| prod | 个人正式使用 | PostgreSQL | 正式 Key |
