# 01 - 产品愿景与范围

> 状态：已评审  
> 最近更新：2026-01-01  
> 所属文档库：[README](../README.md)

## 1. 产品愿景

为个人创作者提供一个**低成本、高质量、可定制化**的 AI 视频生成工作台。

通过多 Agent 协作和云端 API 组合，实现：

- 文生视频
- 图生视频
- 角色一致性
- 自动配音 / 配乐
- 视频拼接与后处理增强

最终输出可直接发布到抖音 / B站 / YouTube 等平台的 **1 分钟左右短视频**。

## 2. 核心价值

1. **摆脱高额 VIP 限制**：按量付费、灵活组合不同模型。
2. **质量超越单一工具**：通过“调度 Agent + 多模型 / 工具链”提升生成质量，达到甚至超过即梦 / 可灵官方效果。
3. **半自动创作**：角色一致性跨视频保持，支持自动剧本生成与配音，大幅降低创作者操作成本。

## 3. 目标用户

- **初期**：本人（个人创作者）。
- **后续**：扩展给其他短视频创作者。

## 4. 核心场景

| 编号 | 场景 | 说明 |
| --- | --- | --- |
| S1 | 一句话成片 | 输入一句话创意 → 自动生成 1 分钟视频（含配音、BGM、字幕）。 |
| S2 | 角色一致性成片 | 上传角色图片 → 生成多个片段并保持角色一致 → 拼接成片。 |
| S3 | 自定义参数 | 手动选择视频比例（16:9 / 9:16 / 1:1）与质量档位，控制成本。 |
| S4 | 历史复用 | 查看历史记录、复用模板、调整参数重新生成。 |

## 5. 产品目标

- 跑通“提示词 → 首帧 → 视频片段 → 拼接 → 配音/BGM/字幕 → 成片”完整链路。
- 单人可维护，API 成本可控。
- Demo 可演示，且具备后续扩展为多用户产品的架构基础。

## 6. 非目标（Won't Have）

- 自研底层生成模型。
- 多用户在线协作。
- 内容审核系统（个人使用阶段，自己把控合规）。

## 7. 成功指标（建议）

| 维度 | 指标 |
| --- | --- |
| 可用性 | 端到端生成成功率 ≥ 80%（含自动重试后） |
| 成本 | 60 秒成片成本控制在 ¥5~30 区间 |
| 效率 | 单次成片全流程耗时可接受（异步，用户无需一直等待） |
| 质量 | 角色一致性与画面质量通过 QualityCheckAgent 阈值 |
