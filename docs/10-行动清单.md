## 2. 推荐项目结构

```text
ai-video-tool/
├── app/
│   ├── api/               # FastAPI 路由
│   ├── core/              # 配置、安全、通用工具
│   ├── models/            # ORM 模型
│   ├── schemas/           # Pydantic Schema
│   ├── services/          # 业务逻辑
│   ├── agents/            # LangGraph Agent 节点
│   ├── providers/         # 外部 API 适配层
│   └── tasks/             # Celery 任务
├── docs/                  # 本文档库
├── tests/
├── docker-compose.yml
├── .env.example
└── README.md
```
