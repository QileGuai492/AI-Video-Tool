# 12 - 任务与错误处理

> 状态：已实现（Celery 自动重试 + TaskRetry 记录）  
> 最近更新：2026-01-01  
> 所属文档库：[README](../README.md)

## 1. 目的

定义异步任务的生命周期、重试、幂等、超时、取消和错误处理机制，避免生成任务出现重复扣费、卡死、丢失等线上问题。

## 2. 任务生命周期

```text
pending → queued → running → completed
                      │
                      ├── failed → retrying → running / failed_final
                      └── cancelled
```

| 状态 | 说明 |
| --- | --- |
| pending | 已创建，尚未进入队列 |
| queued | 已进入 Celery 队列 |
| running | 正在执行某个阶段 |
| completed | 全部阶段成功 |
| failed | 当前阶段失败，可重试 |
| retrying | 正在等待重试 |
| failed_final | 超过最大重试次数，最终失败 |
| cancelled | 用户取消或系统终止 |

## 3. 阶段划分

每个任务由以下阶段组成，按顺序执行：

```text
optimizing_prompt
generating_first_frame
generating_video（可能包含多个片段）
generating_audio
generating_subtitle
post_processing
quality_check
```

每个阶段都应支持：

- 独立记录开始 / 结束时间。
- 独立记录费用。
- 独立记录失败原因。
- 阶段级别重试。

## 4. 重试策略

### 4.1 重试规则

- 默认最大重试次数：**3 次**。
- 重试间隔：指数退避，例如 `30s → 2min → 10min`。
- 可重试错误：网络超时、5xx、限流（429）、临时性 API 错误。
- 不可重试错误：参数错误、鉴权失败、余额不足、内容违规。

### 4.2 重试记录

每次重试必须记录到 `task_retries` 表：

| 字段 | 说明 |
| --- | --- |
| task_id | 任务 ID |
| stage | 失败阶段 |
| attempt | 第几次尝试 |
| error_code | 错误码 |
| error_message | 错误信息 |
| created_at | 时间 |

## 5. 幂等性

- 每个任务生成唯一 `task_id`。
- 客户端重复提交同一请求时，应返回已有任务，而不是创建新任务。
- 建议增加 `idempotency_key`（由客户端生成）或使用相同参数 + 用户 + 短时间窗口去重。
- 外部 API 调用前记录“已发起”，回调 / 轮询结果时按 `task_id` 更新，避免重复扣费。

## 6. 超时处理

| 环节 | 超时时间 | 处理 |
| --- | --- | --- |
| HTTP 请求外部 API | 30s | 标记超时并重试 |
| 文生图 | 60s | 标记超时并重试 |
| 视频生成 | 5~10 分钟 | 轮询超时则继续等待，总超时 30 分钟 |
| TTS | 60s | 标记超时并重试 |
| 后处理（本地 FFmpeg） | 10 分钟 | 标记失败 |
| 整个任务 | 60 分钟 | 强制失败并提示 |

## 7. 取消任务

- 提供 `POST /generate/{task_id}/cancel` 接口。
- 取消后：
  - 未开始的外部调用直接标记 `cancelled`。
  - 已产生的费用照常记录，但不再发起新的付费调用。
  - 已生成的中间文件保留 24 小时，便于用户重新发起。

## 8. 错误码规范

| 错误码 | 含义 | 是否可重试 |
| --- | --- | --- |
| `INVALID_PARAMETER` | 参数错误 | 否 |
| `UNAUTHORIZED` | 未认证 / 无权限 | 否 |
| `TASK_NOT_FOUND` | 任务不存在 | 否 |
| `API_TIMEOUT` | 外部 API 超时 | 是 |
| `API_RATE_LIMITED` | 外部 API 限流 | 是 |
| `API_SERVER_ERROR` | 外部 API 5xx | 是 |
| `API_QUOTA_EXCEEDED` | 余额 / 配额不足 | 否 |
| `CONTENT_REJECTED` | 内容被拒绝 | 否 |
| `INTERNAL_ERROR` | 系统内部错误 | 是 |

## 9. 死信与告警

- 超过最大重试次数的任务进入 `failed_final`，保留错误上下文。
- 连续 5 个任务失败时触发告警。
- 单个 API 连续失败 3 次时自动切换 provider（如可用）。

## 10. 数据表补充建议

新增表：

- `task_retries`：重试历史。
- `task_errors`：错误明细。
- `generation_logs`：每次 API 调用日志与费用。
